## 🚀 Projects

### 🎙️ Echovani AI — AI Dubbing Assistant *(Original Idea)*
> *"Same music. Same emotion. Different language."*

An end-to-end AI dubbing pipeline built from scratch. User uploads audio/video → voice transcribed via **Whisper AI** → translated → re-spoken in a human-like TTS voice, preserving emotion across **24 languages** (12 international + 12 Indian).

`Python` `FastAPI` `Whisper AI` `STT` `TTS` `Flutter` `NLP` `REST API`

🔗 [GitHub](https://github.com/Asiiifa) · Backend complete · Flutter frontend in progress

---

### 😴 Nidra AI — Sleep Health & Stress Predictor *(LIVE)*
> *Personalized ML predictions for sleep quality and stress — trained on real lifestyle data.*

Trained dual **Random Forest Regressor** models on 374 lifestyle records, achieving **~90% R² score** for simultaneous stress and sleep score prediction (0–100 scale). Deployed with Supabase auth, PostgreSQL, Row-Level Security, and per-user prediction history.

`Python` `Flask` `Scikit-learn` `Pandas` `Chart.js` `Supabase` `Render`

🔗 [Live App](https://nidra-ai-drgl.onrender.com) · [GitHub](https://github.com/Asiiifa)

---

### 📋 QuickEntry — Smart Visitor Management *(Original Idea)*
> *Paperless, secure, fast — digital visitor logging for organizations.*

3-factor authentication using **OTP + Biometric + QR Code** via Flutter and Firebase. Firebase Realtime Database syncs logs across devices in under 1 second, with automated daily/weekly PDF report generation.

`Flutter` `Firebase` `OTP Auth` `Biometric` `QR Code`

🔗 [GitHub](https://github.com/Asiiifa/quick-entry-app)
